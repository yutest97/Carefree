Carefree ਇੱਕ ਪੂਰੀ ਤਰ੍ਹਾਂ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਚੱਲਣ ਵਾਲਾ AI ਰਚਨਾ ਟੂਲ ਹੈ। ਪ੍ਰੋਜੈਕਟ, ਸਮੱਗਰੀ, ਗੱਲਬਾਤ ਅਤੇ ਤਿਆਰ ਨਤੀਜੇ ਤੁਹਾਡੇ ਆਪਣੇ ਡਿਵਾਈਸ 'ਤੇ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ, ਅਤੇ ਵਰਤੋਂ ਦਾ ਕੋਈ ਡੇਟਾ ਕਿਸੇ ਸਰਵਰ ਨੂੰ ਨਹੀਂ ਭੇਜਿਆ ਜਾਂਦਾ। ਮਾਡਲ ਸੇਵਾ ਤੁਸੀਂ ਆਪ ਸੈੱਟ ਕਰਦੇ ਹੋ: ਕੋਈ ਵੀ OpenAI-ਅਨੁਕੂਲ ਇੰਟਰਫੇਸ, ਸਥਾਨਕ ComfyUI, ਅਤੇ ਸਥਾਨਕ ਜਾਂ ਸਵੈ-ਹੋਸਟ ਕੀਤੀ TTS ਸੇਵਾ।

### ਰਚਨਾ ਦਾ ਆਮ ਪ੍ਰਵਾਹ

1. **ਸਕ੍ਰਿਪਟ ਅਤੇ ਸਟੋਰੀਬੋਰਡ**: ਟੈਕਸਟ ਨੋਡ ਨਾਲ ਕਹਾਣੀ, ਪਾਤਰ ਸੈਟਿੰਗ ਅਤੇ ਸ਼ਾਟ ਵਰਣਨ ਸੰਗਠਿਤ ਕਰੋ ਅਤੇ ਭਾਸ਼ਾ ਮਾਡਲ ਦੀ ਮਦਦ ਨਾਲ ਸੁਧਾਰੋ।
2. **ਪਾਤਰ ਅਤੇ ਦ੍ਰਿਸ਼**: ਹਵਾਲਾ ਤਸਵੀਰ ਆਯਾਤ ਕਰੋ, ਜਾਂ ਤਸਵੀਰ ਰਚਨਾ ਨੋਡ ਰਾਹੀਂ ਪਾਤਰ, ਦ੍ਰਿਸ਼ ਅਤੇ ਸਟੋਰੀਬੋਰਡ ਤਸਵੀਰਾਂ ਬਣਾਓ।
3. **ਵੀਡੀਓ ਸ਼ਾਟ**: ਟੈਕਸਟ ਅਤੇ ਤਸਵੀਰ ਹਵਾਲੇ ਜੋੜੋ, ਵੀਡੀਓ ਮਾਡਲ ਅਤੇ ਰਚਨਾ ਢੰਗ ਚੁਣੋ, ਅਤੇ ਸ਼ਾਟ ਦਰ ਸ਼ਾਟ ਬਣਾਓ।
4. **ਪ੍ਰੀਵਿਊ ਅਤੇ ਨਿਰਯਾਤ**: ਕੈਨਵਸ ਵਿੱਚ ਤਸਵੀਰਾਂ ਅਤੇ ਵੀਡੀਓ ਕਲਿੱਪਾਂ ਦਾ ਪ੍ਰੀਵਿਊ ਤੇ ਸੰਗਠਨ ਕਰੋ, ਸਮੱਗਰੀ ਡਾਊਨਲੋਡ ਕਰਕੇ ਅੱਗੇ ਪੋਸਟ-ਪ੍ਰੋਡਕਸ਼ਨ ਕਰੋ।

## ਸਰੋਤ ਤੋਂ ਚਲਾਓ

[Bun 1.4.3](https://bun.sh/docs/installation) ਦੀ ਲੋੜ ਹੈ।

```sh
git clone <ਤੁਹਾਡੇ ਰਿਪੋਜ਼ਟਰੀ ਦਾ URL> carefree
cd carefree
bun install --frozen-lockfile

# ਡਿਵੈਲਪਮੈਂਟ ਮੋਡ: Web ਅਤੇ Server ਇਕੱਠੇ ਸ਼ੁਰੂ ਕਰੋ
bun run dev
```

`http://127.0.0.1:3000` ਖੋਲ੍ਹੋ। ਪਹਿਲੀ ਵਾਰ ਸ਼ੁਰੂ ਹੋਣ 'ਤੇ ਬਿਲਟ-ਇਨ ਨੋਡ, ਟੂਲ ਅਤੇ ਪਲੱਗਇਨ ਸ਼ੁਰੂ ਹੁੰਦੇ ਹਨ, ਅਤੇ `myProject` ਵਰਕਿੰਗ ਡਾਇਰੈਕਟਰੀ ਬਣਦੀ ਹੈ।

### ਬਿਲਡ

```sh
# ਨੋਡ, ਐਕਸਟੈਂਸ਼ਨ, Web ਅਤੇ Server ਬਿਲਡ ਕਰੋ
bun run build

# ਵੱਖਰਾ Server ਆਰਟੀਫੈਕਟ ਬਿਲਡ ਕਰੋ
bun run build:server

# ਡੈਸਕਟਾਪ ਕਲਾਇੰਟ ਬਿਲਡ ਕਰੋ
bun run build:desktop
bun run package:desktop
```

Windows ਇੰਸਟਾਲਰ ਡਿਫਾਲਟ ਰੂਪ ਵਿੱਚ ਸਾਈਨ ਨਹੀਂ ਹੁੰਦਾ। ਰਿਲੀਜ਼ ਤੋਂ ਪਹਿਲਾਂ ਹੇਠਾਂ ਦਿੱਤੇ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਸੈੱਟ ਕਰੋ, ਫਿਰ `bun run build:desktop` / `bun run package:desktop` ਆਪਣੇ ਆਪ `signtool` ਨਾਲ ਚਾਰ ਲਾਂਚਰ (`startupLauncher.exe`, `protocolLauncher.exe`, `saveFileDialog.exe`, `updateHelper.exe`), ਇੰਸਟਾਲਰ ਸਹਾਇਕ ਪ੍ਰੋਗਰਾਮ (`checkWebView2.exe`, `checkRunning.exe`) ਅਤੇ ਅੰਤਿਮ `Setup.exe` ਨੂੰ ਸਾਈਨ ਕਰਕੇ ਪੁਸ਼ਟੀ ਕਰੇਗਾ:

| ਵੇਰੀਏਬਲ | ਵਿਆਖਿਆ |
| --- | --- |
| `CAREFREE_SIGN_PFX` | `.pfx` ਸਰਟੀਫਿਕੇਟ ਦਾ ਪੂਰਾ ਪੱਥ; ਸੈੱਟ ਨਾ ਹੋਣ 'ਤੇ ਸਾਈਨ ਛੱਡ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ |
| `CAREFREE_SIGN_PASSWORD` | ਸਰਟੀਫਿਕੇਟ ਦਾ ਪਾਸਵਰਡ; ਸਰਟੀਫਿਕੇਟ ਅਣ-ਐਨਕ੍ਰਿਪਟਿਡ ਹੋਵੇ ਤਾਂ ਖਾਲੀ ਛੱਡੋ |
| `CAREFREE_SIGN_TIMESTAMP_URL` | RFC3161 ਟਾਈਮਸਟੈਂਪ ਸੇਵਾ, ਡਿਫਾਲਟ `http://timestamp.digicert.com` |
| `SIGNTOOL_PATH` | `signtool.exe` ਦਾ ਪੱਥ, ਡਿਫਾਲਟ ਵਿੱਚ Windows SDK ਤੋਂ ਆਪਣੇ ਆਪ ਲੱਭਿਆ ਜਾਂਦਾ ਹੈ |

Windows x64 ਵਾਤਾਵਰਣ ਅਤੇ Windows SDK ਦੀ ਲੋੜ ਹੈ। ਐਪਲੀਕੇਸ਼ਨ ਦਾ ਮੁੱਖ ਪ੍ਰੋਗਰਾਮ ਇੰਕਰੀਮੈਂਟਲ ਅਪਡੇਟ tar ਦੇ ਅੰਦਰ ਹੈ, ਇਸ ਸਾਈਨ ਦੇ ਦਾਇਰੇ ਵਿੱਚ ਨਹੀਂ; ਜੇ ਸਾਈਨ ਦੀ ਲੋੜ ਹੋਵੇ, ਤਾਂ ਪਹਿਲਾਂ ਐਪਲੀਕੇਸ਼ਨ ਫਾਈਲ ਸਾਈਨ ਕਰੋ ਫਿਰ tar ਅਤੇ ਅਪਡੇਟ ਮੈਨੀਫੈਸਟ ਦੁਬਾਰਾ ਬਣਾਓ।

GitHub Actions ਵਿੱਚ ਸਰਟੀਫਿਕੇਟ ਲਈ ਰਿਪੋਜ਼ਟਰੀ Secrets ਵਰਤੋ; ਸੈੱਟ ਕਰਨ ਤੋਂ ਬਾਅਦ Windows ਬਿਲਡ ਆਪਣੇ ਆਪ ਸਾਈਨ ਅਤੇ ਪੁਸ਼ਟੀ ਕਰੇਗਾ:

| Secret | ਵਿਆਖਿਆ |
| --- | --- |
| `CAREFREE_SIGN_PFX_BASE64` | `.pfx` ਸਰਟੀਫਿਕੇਟ ਫਾਈਲ ਦਾ Base64 ਟੈਕਸਟ; ਸੈੱਟ ਨਾ ਹੋਣ 'ਤੇ CI ਸਾਈਨ ਛੱਡ ਦਿੰਦਾ ਹੈ |
| `CAREFREE_SIGN_PASSWORD` | PFX ਐਕਸਪੋਰਟ ਪਾਸਵਰਡ; ਅਣ-ਐਨਕ੍ਰਿਪਟਿਡ ਹੋਵੇ ਤਾਂ ਖਾਲੀ ਛੱਡੋ |

ਸਰਟੀਫਿਕੇਟ ਸਿਰਫ਼ ਬਿਲਡ ਪੜਾਅ ਵਿੱਚ ਅਸਥਾਈ ਤੌਰ 'ਤੇ ਡਿਸਕ 'ਤੇ ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ ਅਤੇ ਕੰਮ ਖਤਮ ਹੋਣ 'ਤੇ ਸਾਫ਼ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ। ਟਾਈਮਸਟੈਂਪ ਪਤਾ `CAREFREE_SIGN_TIMESTAMP_URL` ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਨਾਲ ਬਦਲਿਆ ਜਾ ਸਕਦਾ ਹੈ।

### ਸਰਵਰ

```sh
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

- ਡਿਫਾਲਟ ਰੂਪ ਵਿੱਚ `127.0.0.1:3000` 'ਤੇ ਸੁਣਦਾ ਹੈ ਅਤੇ ਬਾਹਰੀ ਨੈੱਟਵਰਕ ਲਈ ਖੁੱਲ੍ਹਾ ਨਹੀਂ।
- ਪੋਰਟ `TOONFLOW_SERVER_PORT` ਨਾਲ ਬਦਲਿਆ ਜਾ ਸਕਦਾ ਹੈ।
- ਜੇ ਸੱਚਮੁੱਚ ਲੈਨ ਪਹੁੰਚ ਦੀ ਲੋੜ ਹੋਵੇ, ਤਾਂ `TOONFLOW_SERVER_HOST=0.0.0.0` ਸੈੱਟ ਕਰੋ ਅਤੇ ਆਪ ਫਾਇਰਵਾਲ ਨਾਲ ਸਰੋਤ ਸੀਮਿਤ ਕਰੋ; ਬਿਹਤਰ ਹੈ ਕਿ ਐਪ ਵਿੱਚ "ਡਿਵਾਈਸ ਇੰਟਰਕਨੈਕਸ਼ਨ" ਚਾਲੂ ਕਰੋ, ਜੋ ਸਿਰਫ਼ ਲੋੜ ਪੈਣ 'ਤੇ ਵੱਖਰੇ ਪੋਰਟ 'ਤੇ ਸੁਣਦਾ ਹੈ।
- ਸੰਰਚਨਾ, ਪਲੱਗਇਨ ਅਤੇ ਵਰਕਸਪੇਸ ਡਿਫਾਲਟ ਵਿੱਚ `data/` ਵਿੱਚ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ। ਰਿਮੋਟ ਵਰਤੋਂ ਵਿੱਚ SSH ਟਨਲ ਰਾਹੀਂ ਪਹੁੰਚ ਸੰਭਵ ਹੈ:

```sh
ssh -N -L 3000:127.0.0.1:3000 user@server-address
```

## ਮਾਡਲ ਸੰਰਚਿਤ ਕਰੋ

ਸੈਟਿੰਗਾਂ ਵਿੱਚ "Model service" ਖੋਲ੍ਹੋ:

- **ਟੈਕਸਟ ਮਾਡਲ**: OpenAI-ਅਨੁਕੂਲ ਪ੍ਰਦਾਤਾ ਜੋੜੋ, ਇੰਟਰਫੇਸ ਪਤਾ, API Key ਅਤੇ ਮਾਡਲ ਸੂਚੀ ਭਰੋ।
- **ਤਸਵੀਰ / ਵੀਡੀਓ**: ComfyUI ਪ੍ਰਦਾਤਾ ਸਥਾਪਿਤ ਅਤੇ ਸੰਰਚਿਤ ਕਰੋ, ਸਥਾਨਕ ComfyUI ਪਤਾ ਅਤੇ ਵਰਕਫਲੋ ਭਰੋ।
- **ਆਵਾਜ਼**: ਸਥਾਨਕ TTS ਪ੍ਰਦਾਤਾ ਸਥਾਪਿਤ ਕਰੋ, ਡਿਫਾਲਟ ਪਤਾ `http://127.0.0.1:8880/v1` ਹੈ, ਅਤੇ ਕਿਸੇ ਵੀ `/audio/speech`-ਅਨੁਕੂਲ ਸੇਵਾ ਵੱਲ ਇਸ਼ਾਰਾ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ।
- **ਕਸਟਮ ਪ੍ਰਦਾਤਾ**: ਸੈਟਿੰਗਾਂ ਵਿੱਚ `.ts` ਅਡੈਪਟਰ ਫਾਈਲ ਆਯਾਤ ਕਰਕੇ ਕੋਈ ਵੀ ਤੀਜੀ ਧਿਰ ਇੰਟਰਫੇਸ ਵਧਾਇਆ ਜਾ ਸਕਦਾ ਹੈ।

API Key ਸਿਰਫ਼ ਸਥਾਨਕ ਡੇਟਾ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ, ਅੱਪਲੋਡ ਨਹੀਂ ਹੁੰਦਾ।

## Docker

ਰਿਪੋਜ਼ਟਰੀ [Dockerfile](../../Dockerfile), [Compose configuration](../../compose.yaml) ਅਤੇ [build exclusion rules](../../.dockerignore) ਪ੍ਰਦਾਨ ਕਰਦੀ ਹੈ; ਇਮੇਜ Bun 1.4.3 'ਤੇ ਆਧਾਰਿਤ ਹੈ ਅਤੇ FFmpeg ਸ਼ਾਮਲ ਹੈ।

```sh
docker compose up -d --build
```

- `http://127.0.0.1:3000` 'ਤੇ ਪਹੁੰਚੋ।
- ਡੇਟਾ ਨਾਮਜ਼ਦ ਵਾਲਿਊਮ `toonflowData` ਵਿੱਚ ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ (ਕੰਟੇਨਰ ਦੇ ਅੰਦਰ `/app/data/` 'ਤੇ ਮਾਊਂਟ); ਕੰਟੇਨਰ ਰੋਕਣ ਜਾਂ ਦੁਬਾਰਾ ਬਣਾਉਣ ਨਾਲ ਡੇਟਾ ਨਹੀਂ ਜਾਂਦਾ, `docker compose down -v` ਨਾ ਵਰਤੋ।
- ਕੰਟੇਨਰ ਦੇ ਅੰਦਰ ਸੇਵਾ `0.0.0.0` 'ਤੇ ਸੁਣਦੀ ਹੈ, ਪੋਰਟ ਮੈਪਿੰਗ ਜਾਂ ਰਿਵਰਸ ਪ੍ਰੌਕਸੀ ਨਾਲ ਪਹੁੰਚ ਦੇ ਸਰੋਤ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰੋ।

ਆਮ ਕਮਾਂਡਾਂ:

```sh
docker compose logs -f toonflow
docker compose stop
docker compose start
docker compose down
```

## ਡੇਟਾ ਅਤੇ ਪ੍ਰਾਈਵੇਸੀ

- ਐਪ ਕੋਈ ਅਗਿਆਤ ਅੰਕੜੇ ਜਾਂ ਟੈਲੀਮੈਟਰੀ ਡੇਟਾ ਇਕੱਠਾ ਜਾਂ ਅੱਪਲੋਡ ਨਹੀਂ ਕਰਦੀ।
- ਪ੍ਰੋਜੈਕਟ, ਪ੍ਰੋਂਪਟ, ਗੱਲਬਾਤ ਅਤੇ ਬਣਾਈ ਸਮੱਗਰੀ ਸਥਾਨਕ ਡੇਟਾ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ ਸੰਭਾਲੀ ਜਾਂਦੀ ਹੈ।
- ਸਿਰਫ਼ ਮਾਡਲ ਪ੍ਰਦਾਤਾ ਸੰਰਚਿਤ ਕਰਨ ਤੋਂ ਬਾਅਦ ਸੰਬੰਧਿਤ ਇੰਟਰਫੇਸ ਨੂੰ ਬੇਨਤੀਆਂ ਭੇਜੀਆਂ ਜਾਂਦੀਆਂ ਹਨ; ਬੇਨਤੀ ਦੀ ਸਮੱਗਰੀ ਉਸ ਪ੍ਰਦਾਤਾ ਦੀਆਂ ਸੇਵਾ ਸ਼ਰਤਾਂ ਦੇ ਅਧੀਨ ਹੈ।
- ਆਟੋ ਅਪਡੇਟ ਡਿਫਾਲਟ ਵਿੱਚ ਬੰਦ ਹੈ, ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਸਵੈ-ਹੋਸਟ ਕੀਤਾ ਅਪਡੇਟ ਸਰੋਤ ਸੰਰਚਿਤ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ।
