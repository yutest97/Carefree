Carefree সম্পূর্ণ লোকালভাবে চলা একটি AI সৃষ্টি টুল। প্রজেক্ট, অ্যাসেট, কথোপকথন এবং তৈরি করা ফলাফল আপনার নিজের ডিভাইসেই সংরক্ষিত থাকে, এবং কোনো সার্ভারে ব্যবহারের ডেটা পাঠানো হয় না। মডেল সেবা আপনি নিজেই কনফিগার করেন: যেকোনো OpenAI-সামঞ্জস্যপূর্ণ এন্ডপয়েন্ট, লোকাল ComfyUI, এবং লোকাল বা নিজে হোস্ট করা TTS সেবা।

## বৈশিষ্ট্য

| সক্ষমতা | বিবরণ |
| --- | --- |
| অসীম ক্যানভাস | একই ক্যানভাসে স্ক্রিপ্ট, স্টোরিবোর্ড, চরিত্র, দৃশ্য ও ভিডিও ক্লিপ সাজান; গ্রুপিং ও সংযোগ সমর্থিত। |
| টেক্সট সৃষ্টি | যেকোনো OpenAI-সামঞ্জস্যপূর্ণ টেক্সট এন্ডপয়েন্ট যুক্ত করুন এবং টেক্সট নোডে স্ক্রিপ্ট, চরিত্রের সেটিং ও শটের বিবরণ লিখুন। |
| ছবি তৈরি | নিজে হোস্ট করা ComfyUI ওয়ার্কফ্লো দিয়ে চরিত্রের টার্নঅ্যারাউন্ড শিট, দৃশ্য ও স্টোরিবোর্ড ছবি তৈরি করুন। |
| ভিডিও তৈরি | ComfyUI বা তৃতীয় পক্ষের মিডিয়া এন্ডপয়েন্ট দিয়ে ভিডিও শট তৈরি করুন; একাধিক রেফারেন্স অ্যাসেট ও তৈরি বাতিলের সুবিধা। |
| কণ্ঠ তৈরি | OpenAI-সামঞ্জস্যপূর্ণ `/audio/speech` এন্ডপয়েন্ট যুক্ত করুন; লোকাল TTS চালু করে অফলাইনে ডাবিং করুন। |
| অ্যাসেট ব্যবস্থাপনা | ছবি, ভিডিও ও অডিও সবই অ্যাসেট লাইব্রেরিতে যায়, যেখানে আপনি সেগুলো দেখতে, সাজাতে ও ডাউনলোড করতে পারেন। |
| লোকাল-ফার্স্ট | ডিফল্টভাবে সেবা কেবল এই মেশিনেই শোনে; প্রয়োজনে ডিভাইস ইন্টারকানেকশন চালু করে লোকাল নেটওয়ার্কে শেয়ার করুন। |
| বহুভাষিক | ইন্টারফেস ২১টি ভাষা সমর্থন করে। |

উপলভ্য মডেল, রেজোলিউশন, সময়কাল ও অডিও সক্ষমতা আপনার কনফিগার করা প্রোভাইডার ও ওয়ার্কফ্লোর ওপর নির্ভর করে।

### সাধারণ সৃষ্টি প্রবাহ

1. **স্ক্রিপ্ট ও স্টোরিবোর্ড**: টেক্সট নোড দিয়ে গল্প, চরিত্রের সেটিং ও শটের বিবরণ সাজান, এবং ভাষা মডেলের সাহায্যে ধাপে ধাপে উন্নত করুন।
2. **চরিত্র ও দৃশ্য**: রেফারেন্স ছবি আমদানি করুন, অথবা ছবি তৈরির নোড দিয়ে চরিত্র, দৃশ্য ও স্টোরিবোর্ড ছবি তৈরি করুন।
3. **ভিডিও শট**: টেক্সট ও ছবির রেফারেন্স যুক্ত করুন, ভিডিও মডেল ও তৈরির মোড বাছুন, এবং শটে শটে তৈরি করুন।
4. **প্রিভিউ ও এক্সপোর্ট**: ক্যানভাসে ছবি ও ভিডিও ক্লিপ দেখুন ও সাজান, তারপর পোস্ট-প্রোডাকশনের জন্য অ্যাসেট ডাউনলোড করুন।

## ক্লায়েন্ট ইনস্টল করা

| সিস্টেম | বিবরণ |
| --- | --- |
| Windows | ইনস্টলার চালান; ইনস্টলার স্বয়ংক্রিয়ভাবে WebView2 শনাক্ত করে ইনস্টল করে। ইনস্টলের পর অ্যাপ খুলতেই বন্ধ হয়ে গেলে [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) ম্যানুয়ালি ইনস্টল করুন। |
| macOS (Apple Silicon) | Carefree-কে “Applications”-এ টেনে নিয়ে সরাসরি খুলুন। macOS ডেভেলপার যাচাই করতে না পারলে “System Settings → Privacy & Security”-এ গিয়ে অনুমতি দিন। |

`carefree://` URL স্কিম অ্যাপের ভেতরে রিস্টার্ট ও ডিপ লিংকের জন্য ব্যবহৃত হয়।

## সোর্স থেকে চালানো

[Bun 1.4.3](https://bun.sh/docs/installation) প্রয়োজন।

```sh
git clone <আপনার-রিপোজিটরি-URL> carefree
cd carefree
bun install --frozen-lockfile

# ডেভেলপমেন্ট মোড: Web ও Server একসাথে চালু করুন
bun run dev
```

`http://127.0.0.1:3000` খুলুন। প্রথম চালনার সময় অন্তর্নির্মিত নোড, টুল ও প্লাগইন চালু হয় এবং `myProject` ওয়ার্কিং ডিরেক্টরি তৈরি হয়।

### বিল্ড করা

```sh
# নোড, এক্সটেনশন, Web ও Server বিল্ড করুন
bun run build

# স্বতন্ত্র Server আর্টিফ্যাক্ট বিল্ড করুন
bun run build:server

# ডেস্কটপ ক্লায়েন্ট বিল্ড করুন
bun run build:desktop
bun run package:desktop
```

Windows ইনস্টলার ডিফল্টভাবে সাইন করা থাকে না। প্রকাশের আগে নিচের এনভায়রনমেন্ট ভেরিয়েবলগুলো সেট করুন; এরপর `bun run build:desktop` / `bun run package:desktop` স্বয়ংক্রিয়ভাবে `signtool` দিয়ে চারটি লঞ্চার (`startupLauncher.exe`, `protocolLauncher.exe`, `saveFileDialog.exe`, `updateHelper.exe`), ইনস্টলার সহায়ক প্রোগ্রাম (`checkWebView2.exe`, `checkRunning.exe`) এবং চূড়ান্ত `Setup.exe`-এ সাইন ও যাচাই করবে:

| ভেরিয়েবল | বিবরণ |
| --- | --- |
| `CAREFREE_SIGN_PFX` | `.pfx` সার্টিফিকেটের সম্পূর্ণ পথ; সেট না থাকলে সাইনিং বাদ দেওয়া হয় |
| `CAREFREE_SIGN_PASSWORD` | সার্টিফিকেট পাসওয়ার্ড; সার্টিফিকেট এনক্রিপ্ট করা না থাকলে খালি রাখুন |
| `CAREFREE_SIGN_TIMESTAMP_URL` | RFC3161 টাইমস্ট্যাম্প সেবা, ডিফল্ট `http://timestamp.digicert.com` |
| `SIGNTOOL_PATH` | `signtool.exe`-এর পথ; ডিফল্টভাবে Windows SDK থেকে স্বয়ংক্রিয়ভাবে খোঁজা হয় |

Windows x64 পরিবেশ ও Windows SDK প্রয়োজন। অ্যাপের মূল প্রোগ্রামটি ইনক্রিমেন্টাল আপডেট tar-এর ভেতরে থাকে এবং এই সাইনিংয়ের আওতায় পড়ে না; সাইন করতে হলে আগে অ্যাপ ফাইলে সাইন করুন, তারপর tar ও আপডেট ম্যানিফেস্ট আবার তৈরি করুন।

GitHub Actions-এ রিপোজিটরি Secrets দিয়ে সার্টিফিকেট দিন; কনফিগার করার পর Windows বিল্ড স্বয়ংক্রিয়ভাবে সাইন ও যাচাই হয়:

| Secret | বিবরণ |
| --- | --- |
| `CAREFREE_SIGN_PFX_BASE64` | `.pfx` সার্টিফিকেট ফাইলের Base64 টেক্সট; কনফিগার না থাকলে CI সাইনিং বাদ দেয় |
| `CAREFREE_SIGN_PASSWORD` | PFX এক্সপোর্ট পাসওয়ার্ড; এনক্রিপ্ট না থাকলে খালি রাখুন |

সার্টিফিকেট কেবল বিল্ড ধাপের সময় সাময়িকভাবে ডিস্কে রাখা হয় এবং কাজ শেষ হলেই মুছে ফেলা হয়। টাইমস্ট্যাম্প ঠিকানা `CAREFREE_SIGN_TIMESTAMP_URL` এনভায়রনমেন্ট ভেরিয়েবল দিয়ে পরিবর্তন করা যায়।

### সার্ভার

```sh
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

- ডিফল্টভাবে `127.0.0.1:3000`-এ শোনে এবং পাবলিক ইন্টারনেটে উন্মুক্ত নয়।
- `TOONFLOW_SERVER_PORT` দিয়ে পোর্ট পরিবর্তন করা যায়।
- সত্যিই লোকাল নেটওয়ার্ক অ্যাক্সেস দরকার হলে `TOONFLOW_SERVER_HOST=0.0.0.0` সেট করুন এবং ফায়ারওয়াল দিয়ে উৎস সীমিত করুন; বরং অ্যাপে “ডিভাইস ইন্টারকানেকশন” চালু করা বেশি সুপারিশযোগ্য, কারণ এটি কেবল প্রয়োজনে আলাদা পোর্টে শোনে।
- কনফিগারেশন, প্লাগইন ও ওয়ার্কস্পেস ডিফল্টভাবে `data/`-এ সংরক্ষিত হয়। দূর থেকে ব্যবহারের জন্য SSH টানেল দিয়ে সংযোগ করুন:

```sh
ssh -N -L 3000:127.0.0.1:3000 ব্যবহারকারী@সার্ভার-ঠিকানা
```

## মডেল কনফিগার করা

সেটিংসে “মডেল সেবা” খুলুন:

- **টেক্সট মডেল**: OpenAI-সামঞ্জস্যপূর্ণ প্রোভাইডার যোগ করুন, এন্ডপয়েন্ট ঠিকানা, API Key ও মডেল তালিকা দিন।
- **ছবি / ভিডিও**: ComfyUI প্রোভাইডার ইনস্টল ও কনফিগার করুন, লোকাল ComfyUI ঠিকানা ও ওয়ার্কফ্লো দিন।
- **কণ্ঠ**: লোকাল TTS প্রোভাইডার ইনস্টল করুন; ডিফল্ট ঠিকানা `http://127.0.0.1:8880/v1`, এবং `/audio/speech`-এর সাথে সামঞ্জস্যপূর্ণ যেকোনো সেবাতেও নির্দেশ করা যায়।
- **কাস্টম প্রোভাইডার**: সেটিংসে `.ts` অ্যাডাপ্টার ফাইল আমদানি করে যেকোনো তৃতীয় পক্ষের এন্ডপয়েন্ট সম্প্রসারণ করুন।

API Key কেবল লোকাল ডেটা ডিরেক্টরিতে সংরক্ষিত হয়, আপলোড করা হয় না।

## Docker

রিপোজিটরিতে [Dockerfile](../../Dockerfile), [Compose কনফিগারেশন](../../compose.yaml) ও [বিল্ড বাদ দেওয়ার নিয়ম](../../.dockerignore) আছে; ইমেজটি Bun 1.4.3-ভিত্তিক এবং এতে FFmpeg অন্তর্ভুক্ত।

```sh
docker compose up -d --build
```

- `http://127.0.0.1:3000`-এ প্রবেশ করুন।
- ডেটা নামযুক্ত ভলিউম `toonflowData`-এ সংরক্ষিত হয় (কন্টেইনারের ভেতরে `/app/data/`-এ মাউন্ট করা); কন্টেইনার বন্ধ বা পুনরায় তৈরি করলে ডেটা হারায় না, তাই `docker compose down -v` ব্যবহার করবেন না।
- কন্টেইনারের সেবা `0.0.0.0`-এ শোনে; পোর্ট ম্যাপিং বা রিভার্স প্রক্সি দিয়ে অ্যাক্সেসের উৎস নিয়ন্ত্রণ করুন।

সাধারণ কমান্ড:

```sh
docker compose logs -f toonflow
docker compose stop
docker compose start
docker compose down
```

## ডেটা ও গোপনীয়তা

- অ্যাপটি কোনো বেনামী পরিসংখ্যান বা টেলিমেট্রি সংগ্রহ বা রিপোর্ট করে না।
- প্রজেক্ট, প্রম্পট, কথোপকথন ও তৈরি করা বিষয়বস্তু লোকাল ডেটা ডিরেক্টরিতে সংরক্ষিত হয়।
- আপনি মডেল প্রোভাইডার কনফিগার করার পরেই সংশ্লিষ্ট এন্ডপয়েন্টে অনুরোধ পাঠানো হয়; অনুরোধের বিষয়বস্তু সেই প্রোভাইডারের পরিষেবার শর্তাবলির অধীন।
- স্বয়ংক্রিয় আপডেট ডিফল্টভাবে বন্ধ; সেটিংসে নিজে হোস্ট করা আপডেট উৎস কনফিগার করা যায়।
