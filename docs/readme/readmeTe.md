# Carefree｜AI షార్ట్ డ్రామాలు మరియు కామిక్ డ్రామాల కోసం అనంత కాన్వాస్

షార్ట్ డ్రామా, కామిక్ డ్రామా మరియు షార్ట్ వీడియో సృష్టికర్తల కోసం లోకల్ AI సృష్టి సాధనం: అనంత కాన్వాస్లో స్క్రిప్ట్ రాయండి, స్టోరీబోర్డ్లను తయారు చేయండి, పాత్రలు మరియు సన్నివేశాలను నిర్వహించండి, చిత్రాలు మరియు వీడియోలను రూపొందించండి.

Carefree పూర్తిగా లోకల్గా నడిచే AI సృష్టి సాధనం. ప్రాజెక్ట్లు, మీడియా, సంభాషణలు మరియు ఉత్పత్తి ఫలితాలు మీ స్వంత పరికరంలోనే నిల్వ ఉంటాయి; ఏ సర్వర్కూ వినియోగ డేటా పంపబడదు. మోడల్ సేవలను మీరే కాన్ఫిగర్ చేస్తారు: ఏదైనా OpenAI-అనుకూల ఎండ్పాయింట్, లోకల్ ComfyUI, మరియు లోకల్ లేదా స్వీయ-హోస్ట్ చేసిన TTS సేవ.

అందుబాటులో ఉన్న మోడళ్లు, రిజల్యూషన్లు, నిడివులు మరియు ఆడియో సామర్థ్యాలు మీరు కాన్ఫిగర్ చేసిన ప్రొవైడర్లు మరియు వర్క్ఫ్లోలపై ఆధారపడి ఉంటాయి.

### సాధారణ సృష్టి ప్రక్రియ

1. **స్క్రిప్ట్ మరియు స్టోరీబోర్డ్**: టెక్స్ట్ నోడ్లతో కథ, పాత్ర సెట్టింగ్లు మరియు షాట్ వివరాలను ఏర్పాటు చేసి, భాషా మోడల్ సహాయంతో మెరుగుపరచండి.
2. **పాత్రలు మరియు సన్నివేశాలు**: రెఫరెన్స్ చిత్రాలను దిగుమతి చేయండి, లేదా చిత్ర సృష్టి నోడ్లతో పాత్రలు, సన్నివేశాలు మరియు స్టోరీబోర్డ్ చిత్రాలను రూపొందించండి.
3. **వీడియో షాట్లు**: టెక్స్ట్ మరియు చిత్ర రెఫరెన్స్లను కలిపి, వీడియో మోడల్ మరియు సృష్టి మోడ్ను ఎంచుకుని, షాట్ వారీగా రూపొందించండి.
4. **ప్రివ్యూ మరియు ఎక్స్పోర్ట్**: కాన్వాస్లో చిత్రాలు మరియు వీడియో క్లిప్లను చూసి ఏర్పాటు చేయండి, ఆ తర్వాత పోస్ట్-ప్రొడక్షన్ కోసం మీడియాను డౌన్లోడ్ చేయండి.

## సోర్స్ నుండి అమలు చేయడం

[Bun 1.4.3](https://bun.sh/docs/installation) అవసరం.

```sh
git clone <మీ-రిపాజిటరీ-URL> carefree
cd carefree
bun install --frozen-lockfile

# డెవలప్మెంట్ మోడ్: Web మరియు Server ఒకటిగా ప్రారంభించండి
bun run dev
```

`http://127.0.0.1:3000` తెరవండి. మొదటి ప్రారంభంలో అంతర్నిర్మిత నోడ్లు, టూల్లు మరియు ప్లగిన్లు ప్రారంభమై `myProject` పని డైరెక్టరీ సృష్టించబడుతుంది.

### బిల్డ్ చేయడం

```sh
# నోడ్లు, ఎక్స్టెన్షన్లు, Web మరియు Server బిల్డ్ చేయండి
bun run build

# స్వతంత్ర Server ఆర్టిఫ్యాక్ట్లను బిల్డ్ చేయండి
bun run build:server

# డెస్క్టాప్ క్లయింట్ను బిల్డ్ చేయండి
bun run build:desktop
bun run package:desktop
```

Windows ఇన్స్టాలర్లు డిఫాల్ట్గా సంతకం చేయబడవు. ప్రచురించే ముందు కింది ఎన్విరాన్మెంట్ వేరియబుల్స్ సెట్ చేయండి; ఆ తర్వాత `bun run build:desktop` / `bun run package:desktop` స్వయంచాలకంగా `signtool` తో నాలుగు లాంచర్లు (`startupLauncher.exe`, `protocolLauncher.exe`, `saveFileDialog.exe`, `updateHelper.exe`), ఇన్స్టాలర్ సహాయక ప్రోగ్రాములు (`checkWebView2.exe`, `checkRunning.exe`) మరియు చివరి `Setup.exe` కు సంతకం చేసి ధృవీకరిస్తాయి:

| వేరియబుల్ | వివరణ |
| --- | --- |
| `CAREFREE_SIGN_PFX` | `.pfx` సర్టిఫికెట్ పూర్తి మార్గం; సెట్ చేయకుంటే సంతకం చేయడం దాటవేయబడుతుంది |
| `CAREFREE_SIGN_PASSWORD` | సర్టిఫికెట్ పాస్వర్డ్; సర్టిఫికెట్ ఎన్క్రిప్ట్ చేయకుంటే ఖాళీగా ఉంచండి |
| `CAREFREE_SIGN_TIMESTAMP_URL` | RFC3161 టైమ్స్ట్యాంప్ సేవ, డిఫాల్ట్ `http://timestamp.digicert.com` |
| `SIGNTOOL_PATH` | `signtool.exe` మార్గం; డిఫాల్ట్గా Windows SDK నుండి స్వయంచాలకంగా కనుగొనబడుతుంది |

Windows x64 వాతావరణం మరియు Windows SDK అవసరం. యాప్ ప్రధాన ప్రోగ్రామ్ ఇన్క్రిమెంటల్ అప్డేట్ tar లోపల ఉంటుంది, ఈ సంతకం పరిధిలోకి రాదు; దానికి సంతకం చేయాలంటే ముందుగా యాప్ ఫైల్కు సంతకం చేసి, తర్వాత tar మరియు అప్డేట్ మానిఫెస్ట్ను తిరిగి సృష్టించండి.

GitHub Actions లో రిపాజిటరీ Secrets ద్వారా సర్టిఫికెట్ అందించండి; కాన్ఫిగర్ చేసిన తర్వాత Windows బిల్డ్లు స్వయంచాలకంగా సంతకం చేయబడి ధృవీకరించబడతాయి:

| Secret | వివరణ |
| --- | --- |
| `CAREFREE_SIGN_PFX_BASE64` | `.pfx` సర్టిఫికెట్ ఫైల్ యొక్క Base64 టెక్స్ట్; కాన్ఫిగర్ చేయకుంటే CI సంతకం చేయడం దాటవేస్తుంది |
| `CAREFREE_SIGN_PASSWORD` | PFX ఎక్స్పోర్ట్ పాస్వర్డ్; ఎన్క్రిప్ట్ చేయకుంటే ఖాళీగా ఉంచండి |

సర్టిఫికెట్ బిల్డ్ దశ సమయంలో మాత్రమే తాత్కాలికంగా డిస్క్కు రాయబడి, పని ముగిసిన వెంటనే తొలగించబడుతుంది. టైమ్స్ట్యాంప్ చిరునామాను `CAREFREE_SIGN_TIMESTAMP_URL` ఎన్విరాన్మెంట్ వేరియబుల్తో మార్చవచ్చు.

### సర్వర్

```sh
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

- డిఫాల్ట్గా `127.0.0.1:3000` లో వినిపిస్తుంది, పబ్లిక్ ఇంటర్నెట్కు తెరిచి ఉండదు.
- పోర్ట్ను `TOONFLOW_SERVER_PORT` తో మార్చవచ్చు.
- నిజంగా లోకల్ నెట్వర్క్ యాక్సెస్ అవసరమైతే, `TOONFLOW_SERVER_HOST=0.0.0.0` సెట్ చేసి ఫైర్వాల్తో మూలాలను పరిమితం చేయండి; దానికి బదులుగా యాప్లో “డివైస్ ఇంటర్కనెక్షన్” ఆన్ చేయడం మంచిది, అది అవసరమైనప్పుడు మాత్రమే ప్రత్యేక పోర్ట్లో వినిపిస్తుంది.
- కాన్ఫిగరేషన్, ప్లగిన్లు మరియు వర్క్స్పేస్లు డిఫాల్ట్గా `data/` లో నిల్వ ఉంటాయి. రిమోట్ వినియోగం కోసం SSH టన్నెల్ ద్వారా యాక్సెస్ చేయండి:

```sh
ssh -N -L 3000:127.0.0.1:3000 వినియోగదారు@సర్వర్-చిరునామా
```

## మోడళ్లను కాన్ఫిగర్ చేయడం

సెట్టింగ్లలో “మోడల్ సేవలు” తెరవండి:

- **టెక్స్ట్ మోడళ్లు**: OpenAI-అనుకూల ప్రొవైడర్ను జోడించి, ఎండ్పాయింట్ చిరునామా, API Key మరియు మోడల్ జాబితాను నింపండి.
- **చిత్రం / వీడియో**: ComfyUI ప్రొవైడర్ను ఇన్స్టాల్ చేసి కాన్ఫిగర్ చేయండి, లోకల్ ComfyUI చిరునామా మరియు వర్క్ఫ్లోలను నింపండి.
- **వాయిస్**: లోకల్ TTS ప్రొవైడర్ను ఇన్స్టాల్ చేయండి; డిఫాల్ట్ చిరునామా `http://127.0.0.1:8880/v1`, `/audio/speech` కు అనుకూలమైన ఏ సేవకైనా కూడా చూపవచ్చు.
- **కస్టమ్ ప్రొవైడర్లు**: సెట్టింగ్లలో `.ts` అడాప్టర్ ఫైళ్లను దిగుమతి చేసి ఏదైనా థర్డ్-పార్టీ ఎండ్పాయింట్ను విస్తరించవచ్చు.

API Key లోకల్ డేటా డైరెక్టరీలో మాత్రమే నిల్వ ఉంటుంది, అప్లోడ్ చేయబడదు.

## Docker

రిపాజిటరీలో [Dockerfile](../../Dockerfile), [Compose కాన్ఫిగరేషన్](../../compose.yaml) మరియు [బిల్డ్ మినహాయింపు నియమాలు](../../.dockerignore) ఉన్నాయి; ఇమేజ్ Bun 1.4.3 ఆధారంగా రూపొందించబడింది మరియు FFmpeg కలిగి ఉంది.

```sh
docker compose up -d --build
```

- `http://127.0.0.1:3000` తెరవండి.
- డేటా `toonflowData` అనే పేరున్న వాల్యూమ్లో నిల్వ ఉంటుంది (కంటైనర్ లోపల `/app/data/` కు మౌంట్ చేయబడింది); కంటైనర్ను ఆపినా లేదా తిరిగి సృష్టించినా డేటా పోదు, కాబట్టి `docker compose down -v` ఉపయోగించవద్దు.
- కంటైనర్లో సేవ `0.0.0.0` లో వినిపిస్తుంది; పోర్ట్ మ్యాపింగ్ లేదా రివర్స్ ప్రాక్సీ ద్వారా యాక్సెస్ మూలాలను నియంత్రించండి.

సాధారణ ఆదేశాలు:

```sh
docker compose logs -f toonflow
docker compose stop
docker compose start
docker compose down
```

## డేటా మరియు గోపనీయత

- యాప్ అనామక గణాంకాలను లేదా టెలిమెట్రీని సేకరించదు, నివేదించదు.
- ప్రాజెక్ట్లు, ప్రాంప్ట్లు, సంభాషణలు మరియు ఉత్పత్తి కాంటెంట్ లోకల్ డేటా డైరెక్టరీలో నిల్వ ఉంటాయి.
- మీరు మోడల్ ప్రొవైడర్ను కాన్ఫిగర్ చేసిన తర్వాతే సంబంధిత ఎండ్పాయింట్కు అభ్యర్థనలు పంపబడతాయి; అభ్యర్థనల కాంటెంట్ ఆ ప్రొవైడర్ సేవా నిబంధనలకు లోబడి ఉంటుంది.
- ఆటోమేటిక్ అప్డేట్లు డిఫాల్ట్గా ఆఫ్ చేయబడ్డాయి; సెట్టింగ్లలో స్వీయ-హోస్ట్ చేసిన అప్డేట్ మూలాన్ని కాన్ఫిగర్ చేయవచ్చు.
