# Carefree｜AI شارٹ ڈرامہ اور کامک ڈرامہ کے لیے لامحدود کینوس

شارٹ ڈرامہ، کامک ڈرامہ اور مختصر ویڈیو بنانے والوں کے لیے ایک مقامی AI تخلیقی ٹول: لامحدود کینوس پر اسکرپٹ لکھیں، شاٹس تقسیم کریں، کرداروں اور مناظر کا انتظام کریں، اور تصاویر و ویڈیوز بنائیں۔

Carefree ایک مکمل طور پر مقامی طور پر چلنے والا AI تخلیقی ٹول ہے۔ پروجیکٹ، مواد، گفتگو اور تیار شدہ نتائج آپ کے اپنے ڈیوائس پر محفوظ رہتے ہیں، اور استعمال کا کوئی ڈیٹا کسی سرور کو نہیں بھیجا جاتا۔ ماڈل سروس آپ خود ترتیب دیتے ہیں: کوئی بھی OpenAI-مطابق انٹرفیس، مقامی ComfyUI، اور مقامی یا خود میزبان TTS سروس۔

## خصوصیات

| صلاحیت | وضاحت |
| --- | --- |
| لامحدود کینوس | ایک ہی کینوس میں اسکرپٹ، اسٹوری بورڈ، کردار، مناظر اور ویڈیو کلپس ترتیب دیں، گروہ بندی اور کنکشن کے ساتھ۔ |
| متنی تخلیق | کسی بھی OpenAI-مطابق متنی انٹرفیس سے جڑیں اور ٹیکسٹ نوڈ میں اسکرپٹ، کردار کی تفصیلات اور شاٹ کی وضاحت لکھیں۔ |
| تصویر کی تخلیق | خود میزبان ComfyUI ورک فلو کے ذریعے کردار کے تین منظر، مناظر اور اسٹوری بورڈ تصاویر بنائیں۔ |
| ویڈیو کی تخلیق | ComfyUI یا تیسرے فریق کے میڈیا انٹرفیس کے ذریعے ویڈیو شاٹس بنائیں، متعدد حوالہ جاتی مواد اور تخلیق منسوخ کرنے کی سہولت کے ساتھ۔ |
| آواز کی تخلیق | OpenAI-مطابق `/audio/speech` انٹرفیس سے جڑیں؛ مقامی TTS تعینات ہونے پر آف لائن ڈبنگ ممکن ہے۔ |
| مواد کا انتظام | تصاویر، ویڈیوز اور آڈیو سب ایک ہی میڈیا لائبریری میں آتے ہیں، پیش نظارہ، ترتیب اور ڈاؤن لوڈ کے ساتھ۔ |
| مقامی ترجیح | بطور ڈیفالٹ سروس صرف مقامی مشین پر سنتی ہے؛ ضرورت کے مطابق ڈیوائس انٹرکنکشن کھولنے پر لوکل ایریا نیٹ ورک میں اشتراک ممکن ہے۔ |
| کثیر اللسان | انٹرفیس 21 زبانوں کی حمایت کرتا ہے۔ |

دستیاب ماڈلز، ریزولوشن، دورانیہ اور آڈیو صلاحیتیں آپ کے ترتیب دیے گئے فراہم کنندہ اور ورک فلو پر منحصر ہیں۔

### تخلیق کا عام عمل

1. **اسکرپٹ اور اسٹوری بورڈ**: ٹیکسٹ نوڈ کے ذریعے کہانی، کردار کی تفصیلات اور شاٹ کی وضاحت ترتیب دیں اور لینگویج ماڈل کی مدد سے بہتر بنائیں۔
2. **کردار اور مناظر**: حوالہ جاتی تصویر درآمد کریں، یا امیج جنریشن نوڈ کے ذریعے کردار، مناظر اور اسٹوری بورڈ تصاویر بنائیں۔
3. **ویڈیو شاٹس**: متن اور تصویر کے حوالہ جات جوڑیں، ویڈیو ماڈل اور تخلیق کا طریقہ منتخب کریں، اور شاٹ بہ شاٹ تخلیق کریں۔
4. **پیش نظارہ اور ایکسپورٹ**: کینوس میں تصاویر اور ویڈیو کلپس کا پیش نظارہ اور ترتیب کریں، مواد ڈاؤن لوڈ کر کے مزید پوسٹ پروڈکشن کریں۔

## کلائنٹ انسٹال کریں

| سسٹم | وضاحت |
| --- | --- |
| Windows | انسٹالر چلائیں؛ انسٹالر خود بخود WebView2 کا پتہ لگا کر انسٹال کر دے گا۔ اگر انسٹال کے بعد کھولنے پر کریش ہو تو [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) دستی طور پر انسٹال کریں۔ |
| macOS (Apple Silicon) | Carefree کو "Applications" میں گھسیٹ کر براہ راست کھولیں۔ اگر ڈویلپر کی تصدیق نہ ہونے کا پیغام آئے تو "System Settings → Privacy & Security" میں کھولنے کی اجازت دیں۔ |

پروٹوکول `carefree://` استعمال ہوتا ہے، جو کلائنٹ کے اندر ری اسٹارٹ اور ڈیپ لنک نیویگیشن کے لیے ہے۔

## سورس سے چلائیں

[Bun 1.4.3](https://bun.sh/docs/installation) درکار ہے۔

```sh
git clone <آپ کی ریپوزٹری کا URL> carefree
cd carefree
bun install --frozen-lockfile

# ڈویلپمنٹ موڈ: Web اور Server ایک ساتھ شروع کریں
bun run dev
```

`http://127.0.0.1:3000` کھولیں۔ پہلی بار اسٹارٹ پر بلٹ ان نوڈز، ٹولز اور پلگ انز کی ابتدا ہوتی ہے، اور `myProject` ورکنگ ڈائریکٹری بنتی ہے۔

### بلڈ

```sh
# نوڈز، ایکسٹینشنز، Web اور Server بلڈ کریں
bun run build

# الگ Server آرٹیفیکٹ بلڈ کریں
bun run build:server

# ڈیسک ٹاپ کلائنٹ بلڈ کریں
bun run build:desktop
bun run package:desktop
```

Windows انسٹالر بطور ڈیفالٹ دستخط شدہ نہیں ہوتا۔ ریلیز سے پہلے نیچے دیے گئے ماحولی متغیرات مقرر کریں، پھر `bun run build:desktop` / `bun run package:desktop` خود بخود `signtool` کے ذریعے چار لانچرز (`startupLauncher.exe`، `protocolLauncher.exe`، `saveFileDialog.exe`، `updateHelper.exe`)، انسٹالر معاون پروگرامز (`checkWebView2.exe`، `checkRunning.exe`) اور حتمی `Setup.exe` پر دستخط کر کے تصدیق کرے گا:

| متغیر | وضاحت |
| --- | --- |
| `CAREFREE_SIGN_PFX` | `.pfx` سرٹیفکیٹ کا مطلق راستہ؛ مقرر نہ ہو تو دستخط چھوڑ دیے جاتے ہیں |
| `CAREFREE_SIGN_PASSWORD` | سرٹیفکیٹ کا پاس ورڈ؛ سرٹیفکیٹ غیر خفیہ ہو تو خالی رکھیں |
| `CAREFREE_SIGN_TIMESTAMP_URL` | RFC3161 ٹائم اسٹیمپ سروس، ڈیفالٹ `http://timestamp.digicert.com` |
| `SIGNTOOL_PATH` | `signtool.exe` کا راستہ، ڈیفالٹ میں Windows SDK سے خود بخود تلاش ہوتا ہے |

Windows x64 ماحول اور Windows SDK درکار ہے۔ ایپلیکیشن کا مرکزی پروگرام انکریمنٹل اپڈیٹ tar کے اندر ہے، اس دستخط کی حد میں نہیں؛ اگر دستخط درکار ہوں تو پہلے ایپلیکیشن فائل پر دستخط کریں پھر tar اور اپڈیٹ مینوفسٹ دوبارہ بنائیں۔

GitHub Actions میں سرٹیفکیٹ کے لیے ریپوزٹری Secrets استعمال کریں؛ ترتیب دینے کے بعد Windows بلڈ خود بخود دستخط اور تصدیق کرے گا:

| Secret | وضاحت |
| --- | --- |
| `CAREFREE_SIGN_PFX_BASE64` | `.pfx` سرٹیفکیٹ فائل کا Base64 متن؛ ترتیب نہ ہو تو CI دستخط چھوڑ دیتا ہے |
| `CAREFREE_SIGN_PASSWORD` | PFX ایکسپورٹ پاس ورڈ؛ غیر خفیہ ہو تو خالی رکھیں |

سرٹیفکیٹ صرف بلڈ مرحلے میں عارضی طور پر ڈسک پر محفوظ ہوتا ہے اور کام ختم ہونے پر صاف کر دیا جاتا ہے۔ ٹائم اسٹیمپ ایڈریس `CAREFREE_SIGN_TIMESTAMP_URL` ماحولی متغیر سے تبدیل کیا جا سکتا ہے۔

### سرور

```sh
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

- بطور ڈیفالٹ `127.0.0.1:3000` پر سنتا ہے اور بیرونی نیٹ ورک پر کھلا نہیں۔
- پورٹ `TOONFLOW_SERVER_PORT` سے تبدیل کیا جا سکتا ہے۔
- اگر واقعی لوکل ایریا نیٹ ورک تک رسائی درکار ہو تو `TOONFLOW_SERVER_HOST=0.0.0.0` مقرر کریں اور خود فائر وال سے ماخذ کو محدود کریں؛ بہتر یہ ہے کہ ایپ میں "ڈیوائس انٹرکنکشن" کھولیں، جو صرف ضرورت پر الگ پورٹ سنتا ہے۔
- ترتیب، پلگ انز اور ورک اسپیس بطور ڈیفالٹ `data/` میں محفوظ ہوتے ہیں۔ ریموٹ استعمال میں SSH ٹنل سے رسائی ممکن ہے:

```sh
ssh -N -L 3000:127.0.0.1:3000 user@server-address
```

## ماڈلز کی ترتیب

ترتیبات میں "Model service" کھولیں:

- **متنی ماڈل**: OpenAI-مطابق فراہم کنندہ شامل کریں، انٹرفیس ایڈریس، API Key اور ماڈل کی فہرست درج کریں۔
- **تصویر / ویڈیو**: ComfyUI فراہم کنندہ انسٹال اور ترتیب دیں، مقامی ComfyUI ایڈریس اور ورک فلو درج کریں۔
- **آواز**: مقامی TTS فراہم کنندہ انسٹال کریں، ڈیفالٹ ایڈریس `http://127.0.0.1:8880/v1` ہے، اور کسی بھی `/audio/speech`-مطابق سروس کی طرف اشارہ کیا جا سکتا ہے۔
- **حسب ضرورت فراہم کنندہ**: ترتیبات میں `.ts` اڈاپٹر فائل درآمد کر کے کسی بھی تیسرے فریق کے انٹرفیس کو بڑھایا جا سکتا ہے۔

API Key صرف مقامی ڈیٹا ڈائریکٹری میں محفوظ ہوتا ہے، اپ لوڈ نہیں ہوتا۔

## Docker

ریپوزٹری [Dockerfile](../../Dockerfile)، [Compose configuration](../../compose.yaml) اور [build exclusion rules](../../.dockerignore) فراہم کرتی ہے؛ امیج Bun 1.4.3 پر مبنی ہے اور FFmpeg شامل ہے۔

```sh
docker compose up -d --build
```

- `http://127.0.0.1:3000` تک رسائی کریں۔
- ڈیٹا نامزد والیوم `toonflowData` میں محفوظ ہوتا ہے (کنٹینر کے اندر `/app/data/` پر ماؤنٹ)؛ کنٹینر روکنے یا دوبارہ بنانے سے ڈیٹا ضائع نہیں ہوتا، `docker compose down -v` استعمال نہ کریں۔
- کنٹینر کے اندر سروس `0.0.0.0` پر سنتی ہے، پورٹ میپنگ یا ریورس پراکسی سے رسائی کے ماخذ کو کنٹرول کریں۔

عام کمانڈز:

```sh
docker compose logs -f toonflow
docker compose stop
docker compose start
docker compose down
```

## ڈیٹا اور رازداری

- ایپ کوئی گمنام شماریات یا ٹیلی میٹری ڈیٹا جمع یا اپ لوڈ نہیں کرتی۔
- پروجیکٹ، پرومپٹ، گفتگو اور تخلیق شدہ مواد مقامی ڈیٹا ڈائریکٹری میں محفوظ رہتے ہیں۔
- صرف ماڈل فراہم کنندہ ترتیب دینے کے بعد متعلقہ انٹرفیس کو درخواستیں بھیجی جاتی ہیں؛ درخواست کا مواد اس فراہم کنندہ کی سروس شرائط کے تابع ہے۔
- خودکار اپڈیٹ بطور ڈیفالٹ بند ہے، ترتیبات میں خود میزبان اپڈیٹ ماخذ ترتیب دیا جا سکتا ہے۔
