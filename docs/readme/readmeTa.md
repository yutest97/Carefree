# Carefree｜AI ஷார்ட் டிராமா மற்றும் கமிக் டிராமாவிற்கான எல்லையற்ற கேன்வாஸ்

ஷார்ட் டிராமா, கமிக் டிராமா மற்றும் ஷார்ட் வீடியோ உருவாக்குநர்களுக்கான லோக்கல் AI உருவாக்கக் கருவி: எல்லையற்ற கேன்வாஸில் திரைக்கதை எழுதுங்கள், ஸ்டோரிபோர்டுகளை உருவாக்குங்கள், பாத்திரங்கள் மற்றும் காட்சிகளை நிர்வகிக்குங்கள், படங்கள் மற்றும் வீடியோக்களை உருவாக்குங்கள்.

Carefree முழுவதும் லோக்கலாக இயங்கும் AI உருவாக்கக் கருவி. திட்டங்கள், மீடியாக்கள், உரையாடல்கள் மற்றும் உருவாக்கப்பட்ட முடிவுகள் உங்கள் சொந்த சாதனத்திலேயே சேமிக்கப்படும்; எந்தச் சேவையகத்திற்கும் பயன்பாட்டுத் தரவு அனுப்பப்படாது. மாடல் சேவைகளை நீங்களே அமைக்கிறீர்கள்: எந்தவொரு OpenAI-இணக்கமான எண்ட்பாயிண்ட், லோக்கல் ComfyUI, மற்றும் லோக்கல் அல்லது சொந்தமாக ஹோஸ்ட் செய்த TTS சேவை.

### வழக்கமான உருவாக்கச் செயல்பாடு

1. **திரைக்கதை மற்றும் ஸ்டோரிபோர்டு**: உரை நோட்களில் கதை, பாத்திர அமைப்புகள் மற்றும் ஷாட் விவரங்களை ஒழுங்கமைத்து, மொழி மாடலின் உதவியுடன் மேம்படுத்துங்கள்.
2. **பாத்திரங்கள் மற்றும் காட்சிகள்**: குறிப்புப் படங்களை இறக்குமதி செய்யுங்கள், அல்லது பட உருவாக்க நோட்கள் மூலம் பாத்திரங்கள், காட்சிகள் மற்றும் ஸ்டோரிபோர்டு படங்களை உருவாக்குங்கள்.
3. **வீடியோ ஷாட்கள்**: உரை மற்றும் படக் குறிப்புகளை இணைத்து, வீடியோ மாடலைத் தேர்ந்தெடுத்து, ஷாட் வாரியாக உருவாக்குங்கள்.
4. **பார்வை மற்றும் ஏற்றுமதி**: கேன்வாஸில் படங்கள் மற்றும் வீடியோ கிளிப்புகளைப் பார்த்து ஒழுங்கமைத்து, பின்னர் தயாரிப்புக்குப் பிந்தைய வேலைக்கு மீடியாக்களைப் பதிவிறக்குங்கள்.

| சிஸ்டம் | விவரம் |

`carefree://` URL ஸ்கீம் ஆப் உள்ளே மறுதொடக்கம் மற்றும் டீப் லிங்குகளுக்குப் பயன்படுத்தப்படுகிறது.

## மூலத்திலிருந்து இயக்குதல்

[Bun 1.4.3](https://bun.sh/docs/installation) தேவை.

```sh
git clone <உங்கள்-ரெப்பொசிடரி-URL> carefree
cd carefree
bun install --frozen-lockfile

# டெவல்ப்மென்ட் மோட்: Web மற்றும் Server ஒன்றாகத் தொடங்கும்
bun run dev
```

`http://127.0.0.1:3000` ஐத் திறக்கவும். முதல் இயக்கத்தில் உள்ளமைந்த நோட்கள், கருவிகள் மற்றும் பிளக்கின்கள் தொடங்கி, `myProject` பணியிட கோப்பகம் உருவாக்கப்படும்.

### கட்டமைத்தல்

```sh
# நோட்கள், எக்ஸ்டென்ஷன்கள், Web மற்றும் Server கட்டமைக்கவும்
bun run build

# தனித்த Server ஆர்ட்டிஃபாக்ட்களைக் கட்டமைக்கவும்
bun run build:server

# டெஸ்க்டாப் கிளையண்டைக் கட்டமைக்கவும்
bun run build:desktop
bun run package:desktop
```

Windows இன்ஸ்டாலர்கள் இயல்பாகக் கையொப்பமிடப்படுவதில்லை. வெளியிடும் முன் கீழ்க்கண்ட சூழல் மாறிகளை அமைக்கவும்; பிறகு `bun run build:desktop` / `bun run package:desktop` தானாக `signtool` மூலம் நான்கு லாஞ்சர்கள் (`startupLauncher.exe`, `protocolLauncher.exe`, `saveFileDialog.exe`, `updateHelper.exe`), இன்ஸ்டாலர் உதவி மென்பொருட்கள் (`checkWebView2.exe`, `checkRunning.exe`) மற்றும் இறுதி `Setup.exe` ஆகியவற்றிற்கு கையொப்பமிட்டு சரிபார்க்கும்:

| மாறி | விவரம் |
| --- | --- |
| `CAREFREE_SIGN_PFX` | `.pfx` சான்றிதழின் முழுப் பாதை; அமைக்கப்படாவிட்டால் கையொப்பமிடுதல் விடப்படும் |
| `CAREFREE_SIGN_PASSWORD` | சான்றிதழ் கடவுச்சொல்; சான்றிதழ் என்க்ரிப்ட் செய்யப்படாவிட்டால் காலியாக விடவும் |
| `CAREFREE_SIGN_TIMESTAMP_URL` | RFC3161 டைம்ஸ்டாம்ப் சேவை, இயல்பு `http://timestamp.digicert.com` |
| `SIGNTOOL_PATH` | `signtool.exe` பாதை; இயல்பாக Windows SDK-இல் தானாகவே கண்டறியப்படும் |

Windows x64 சூழல் மற்றும் Windows SDK தேவை. ஆப்களின் முதன்மை நிரல் அதிகரிக்கும் (incremental) புதுப்பிப்பு tar-க்குள் இருப்பதால் இந்தக் கையொப்பமிடலில் அடங்காது; அதைக் கையொப்பமிட வேண்டுமானால் முதலில் ஆப் கோப்பைக் கையொப்பமிட்டு, பின்னர் tar மற்றும் புதுப்பிப்பு மேனிஃபெஸ்ட்டை மீண்டும் உருவாக்கவும்.

GitHub Actions-இல் கையொப்பத்தை ரெப்பொசிடரியின் Secrets மூலம் வழங்கவும்; அமைத்த பிறகு Windows கட்டமைப்புகள் தானாகவே கையொப்பமிட்டு சரிபார்க்கப்படும்:

| Secret | விவரம் |
| --- | --- |
| `CAREFREE_SIGN_PFX_BASE64` | `.pfx` சான்றிதழ் கோப்பின் Base64 உரை; அமைக்கப்படாவிட்டால் CI கையொப்பமிடுதலை விடும் |
| `CAREFREE_SIGN_PASSWORD` | PFX ஏற்றுமதி கடவுச்சொல்; என்க்ரிப்ட் செய்யப்படாவிட்டால் காலியாக விடவும் |

கையொப்பம் கட்டமைப்பு படிநிலையின் போது மட்டும் தற்காலிகமாக வட்டில் எழுதப்பட்டு, பணி முடிந்ததும் அழிக்கப்படும். டைம்ஸ்டாம்ப் முகவரியை `CAREFREE_SIGN_TIMESTAMP_URL` சூழல் மாறியால் மாற்றலாம்.

### சேவையகம்

```sh
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

- இயல்பாக `127.0.0.1:3000`-ல் மட்டும் கேட்கும், பொதுவான இணையத்திற்கு திறந்திருக்காது.
- துறையை `TOONFLOW_SERVER_PORT` மூலம் மாற்றலாம்.
- உண்மையிலேயே லோக்கல் நெட்வொர்க் அணுகல் தேவைப்பட்டால், `TOONFLOW_SERVER_HOST=0.0.0.0` என அமைத்து ஃபயர்வால் மூலம் மூலங்களைக் கட்டுப்படுத்துங்கள்; அதற்குப் பதிலாக ஆப்பில் “சாதன இணைப்பை” இயக்குவது நல்லது, அது தேவைப்படும்போது மட்டும் தனித் துறையில் கேட்கும்.
- அமைப்புகள், பிளக்கின்கள் மற்றும் பணியிடங்கள் இயல்பாக `data/`-ல் சேமிக்கப்படும். தொலைவிலிருந்து பயன்படுத்த SSH சுரங்கப்பாதை வழியாக அணுகவும்:

```sh
ssh -N -L 3000:127.0.0.1:3000 பயனர்@சேவையக-முகவரி
```

## மாடல்களை அமைத்தல்

அமைப்புகளில் “மாடல் சேவைகள்” ஐத் திறக்கவும்:

- **உரை மாடல்கள்**: OpenAI-இணக்கமான வழங்குநரைச் சேர்த்து, எண்ட்பாயிண்ட் முகவரி, API Key மற்றும் மாடல் பட்டியலை நிரப்பவும்.
- **படம் / வீடியோ**: ComfyUI வழங்குநரை நிறுவி அமைக்கவும், லோக்கல் ComfyUI முகவரி மற்றும் வேலைப்பாய்வுகளை நிரப்பவும்.
- **குரல்**: லோக்கல் TTS வழங்குநரை நிறுவவும்; இயல்பு முகவரி `http://127.0.0.1:8880/v1`, மேலும் `/audio/speech` உடன் இணக்கமான எந்தச் சேவைக்கும் சுட்டலாம்.
- **தனிப்பயன் வழங்குநர்கள்**: அமைப்புகளில் `.ts` அடாப்டர் கோப்புகளை இறக்குமதி செய்து எந்த மூன்றாம் தரப்பு எண்ட்பாயிண்டையும் விரிவாக்கலாம்.

API Key லோக்கல் தரவு கோப்பகத்தில் மட்டுமே சேமிக்கப்படும், பதிவேற்றப்படாது.

## Docker

ரெப்பொசிடரியில் [Dockerfile](../../Dockerfile), [Compose அமைப்பு](../../compose.yaml) மற்றும் [கட்டமைப்பு விலக்கல் விதிகள்](../../.dockerignore) உள்ளன; இமேஜ் Bun 1.4.3 அடிப்படையிலானது மற்றும் FFmpeg உள்ளடங்கியது.

```sh
docker compose up -d --build
```

- `http://127.0.0.1:3000` ஐ அணுகவும்.
- தரவு `toonflowData` எனும் பெயரிடப்பட்ட வால்யூமில் சேமிக்கப்படும் (கன்டெய்னருக்குள் `/app/data/`-ல் மவுண்ட் செய்யப்பட்டுள்ளது); கன்டெய்னரை நிறுத்தினாலோ மீண்டும் உருவாக்கினாலோ தரவு போகாது, எனவே `docker compose down -v` ஐப் பயன்படுத்த வேண்டாம்.
- கன்டெய்னருக்குள் சேவை `0.0.0.0`-ல் கேட்கும்; போர்ட் மேப்பிங் அல்லது ரிவர்ஸ் புராக்ஸி மூலம் அணுகல் மூலங்களைக் கட்டுப்படுத்துங்கள்.

சாதாரண கட்டளைகள்:

```sh
docker compose logs -f toonflow
docker compose stop
docker compose start
docker compose down
```

## தரவு மற்றும் தனியுரிமை

- ஆப் அநாமதேய புள்ளிவிவரங்களையோ டெலிமெட்ரியையோ சேகரிக்கவோ அறிக்கையிடவோ இல்லை.
- திட்டங்கள், ப்ராம்ப்ட்கள், உரையாடல்கள் மற்றும் உருவாக்கப்பட்ட உள்ளடக்கம் லோக்கல் தரவு கோப்பகத்தில் சேமிக்கப்படும்.
- நீங்கள் மாடல் வழங்குநரை அமைத்த பிறகே தொடர்புடைய எண்ட்பாயிண்டிற்கு கோரிக்கைகள் அனுப்பப்படும்; கோரிக்கையின் உள்ளடக்கம் அந்த வழங்குநரின் சேவை விதிமுறைகளுக்கு உட்பட்டது.
- தானியங்கி புதுப்பிப்புகள் இயல்பாக முடக்கப்பட்டுள்ளன; அமைப்புகளில் சொந்தமாக ஹோஸ்ட் செய்த புதுப்பிப்பு மூலத்தை அமைக்கலாம்.
