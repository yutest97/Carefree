# Carefree｜AI शॉर्ट ड्रामा आणि कॉमिक ड्रामासाठी अनंत कॅनव्हास

शॉर्ट ड्रामा, कॉमिक ड्रामा आणि शॉर्ट व्हिडिओ निर्मात्यांसाठी स्थानिक AI निर्मिती साधन: अनंत कॅनव्हासवर पटकथा लिहा, स्टोरीबोर्ड तयार करा, पात्र आणि दृश्ये व्यवस्थापित करा, आणि प्रतिमा व व्हिडिओ तयार करा.

Carefree पूर्णपणे स्थानिक पातळीवर चालणारे AI निर्मिती साधन आहे. प्रकल्प, माध्यमे, संभाषणे आणि तयार झालेले निकाल तुमच्याच उपकरणावर साठवले जातात, आणि कोणत्याही सर्व्हरवर वापराचा डेटा पाठवला जात नाही. मॉडेल सेवा तुम्हीच कॉन्फिगर करता: कोणतेही OpenAI-सुसंगत एंडपॉइंट, स्थानिक ComfyUI, आणि स्थानिक किंवा स्वयं-होस्ट केलेली TTS सेवा.

## वैशिष्ट्ये

| क्षमता | तपशील |
| --- | --- |
| अनंत कॅनव्हास | एकाच कॅनव्हासवर पटकथा, स्टोरीबोर्ड, पात्र, दृश्ये आणि व्हिडिओ क्लिप व्यवस्थित करा; ग्रूपिंग आणि जोडण्या समर्थित आहेत. |
| मजकूर निर्मिती | कोणतेही OpenAI-सुसंगत मजकूर एंडपॉइंट जोडा आणि मजकूर नोडमध्ये पटकथा, पात्रांची रचना आणि शॉट वर्णन लिहा. |
| प्रतिमा निर्मिती | स्वयं-होस्ट केलेल्या ComfyUI वर्कफ्लोद्वारे पात्रांचे टर्नअराउंड शीट, दृश्ये आणि स्टोरीबोर्ड प्रतिमा तयार करा. |
| व्हिडिओ निर्मिती | ComfyUI किंवा तृतीय-पक्षीय मीडिया एंडपॉइंटद्वारे व्हिडिओ शॉट तयार करा; अनेक संदर्भ माध्यमे आणि निर्मिती रद्द करण्याची सोय. |
| आवाज निर्मिती | OpenAI-सुसंगत `/audio/speech` एंडपॉइंट जोडा; स्थानिक TTS तैनात करून ऑफलाइन डबिंग करा. |
| माध्यम व्यवस्थापन | प्रतिमा, व्हिडिओ आणि ऑडिओ सर्व माध्यम संग्रहात जातात; तिथे तुम्ही त्यांचे पूर्वावलोकन, वर्गीकरण आणि डाउनलोड करू शकता. |
| स्थानिक-प्राधान्य | डीफॉल्टनुसार सेवा फक्त याच मशीनवर ऐकते; गरज असल्यास डिव्हाइस इंटरकनेक्शन सुरू करून स्थानिक नेटव्हर्कमध्ये सामायिक करा. |
| बहुभाषिक | इंटरफेस 21 भाषांना समर्थन देतो. |

उपलब्ध मॉडेल, रिझोल्युशन, कालावधी आणि ऑडिओ क्षमता तुम्ही कॉन्फिगर केलेल्या पुरवठादारांवर आणि वर्कफ्लोंवर अवलंबून असतात.

### नेहमीचा निर्मिती प्रवाह

1. **पटकथा आणि स्टोरीबोर्ड**: मजकूर नोडने कथा, पात्रांची रचना आणि शॉट वर्णन व्यवस्थित करा आणि भाषा मॉडेलच्या मदतीने सुधारत जा.
2. **पात्र आणि दृश्ये**: संदर्भ प्रतिमा आयात करा, किंवा प्रतिमा निर्मिती नोडद्वारे पात्र, दृश्ये आणि स्टोरीबोर्ड प्रतिमा तयार करा.
3. **व्हिडिओ शॉट**: मजकूर आणि प्रतिमा संदर्भ जोडा, व्हिडिओ मॉडेल आणि निर्मिती पद्धत निवडा आणि शॉटनुसार तयार करा.
4. **पूर्वावलोकन आणि निर्यात**: कॅनव्हासवर प्रतिमा आणि व्हिडिओ क्लिप पाहा व व्यवस्थित करा, नंतर पोस्ट-प्रोडक्शनसाठी माध्यमे डाउनलोड करा.

## क्लायंट स्थापित करणे

| सिस्टम | तपशील |
| --- | --- |
| Windows | इंस्टॉलर चालवा; इंस्टॉलर स्वयंचलितपणे WebView2 शोधून स्थापित करतो. स्थापनेनंतर अॅप उघडताच बंद होत असेल, तर [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) स्वतः स्थापित करा. |
| macOS (Apple Silicon) | Carefree ला “Applications” मध्ये ओढा आणि थेट उघडा. macOS डेव्हलपरची पडताळणी करू शकत नाही असे सांगत असेल, तर “System Settings → Privacy & Security” मध्ये परवानगी द्या. |

`carefree://` URL स्कीम अॅपमधील रीस्टार्ट आणि डीप लिंकसाठी वापरली जाते.

## स्त्रोतातून चालवणे

[Bun 1.4.3](https://bun.sh/docs/installation) आवश्यक आहे.

```sh
git clone <तुमच्या-रिपॉझिटरीचा-URL> carefree
cd carefree
bun install --frozen-lockfile

# डेव्हलपमेंट मोड: Web आणि Server एकत्र सुरू करा
bun run dev
```

`http://127.0.0.1:3000` उघडा. पहिल्या सुरुवातीला अंगभूत नोड, साधने आणि प्लगइन सुरू होतात आणि `myProject` कार्यरत डिरेक्टरी तयार होते.

### बिल्ड करणे

```sh
# नोड, एक्स्टेंशन, Web आणि Server बिल्ड करा
bun run build

# स्वतंत्र Server आर्टिफॅक्ट बिल्ड करा
bun run build:server

# डेस्कटॉप क्लायंट बिल्ड करा
bun run build:desktop
bun run package:desktop
```

Windows इंस्टॉलर डीफॉल्टनुसार स्वाक्षरीकृत नसतात. प्रकाशित करण्यापूर्वी खालील एन्व्हायर्नमेंट व्हेरिएबल सेट करा; त्यानंतर `bun run build:desktop` / `bun run package:desktop` स्वयंचलितपणे `signtool` ने चार लॉन्चर (`startupLauncher.exe`, `protocolLauncher.exe`, `saveFileDialog.exe`, `updateHelper.exe`), इंस्टॉलर सहायक प्रोग्राम (`checkWebView2.exe`, `checkRunning.exe`) आणि अंतिम `Setup.exe` ला स्वाक्षरी करून पडताळणी करतील:

| व्हेरिएबल | तपशील |
| --- | --- |
| `CAREFREE_SIGN_PFX` | `.pfx` प्रमाणपत्राचा संपूर्ण पथ; सेट नसेल तर स्वाक्षरी वगळली जाते |
| `CAREFREE_SIGN_PASSWORD` | प्रमाणपत्र संकेतशब्द; प्रमाणपत्र एन्क्रिप्ट नसेल तर रिकामा ठेवा |
| `CAREFREE_SIGN_TIMESTAMP_URL` | RFC3161 टाइमस्टॅम्प सेवा, डीफॉल्ट `http://timestamp.digicert.com` |
| `SIGNTOOL_PATH` | `signtool.exe` चा पथ; डीफॉल्टनुसार Windows SDK मधून स्वयंचलितपणे शोधला जातो |

Windows x64 वातावरण आणि Windows SDK आवश्यक आहे. अॅपचा मुख्य प्रोग्राम इन्क्रिमेंटल अपडेट tar मध्ये असल्याने या स्वाक्षरीच्या व्याप्तीत येत नाही; तो स्वाक्षरीकृत करायचा असल्यास प्रथम अॅप फाइलवर स्वाक्षरी करा, नंतर tar आणि अपडेट मॅनिफेस्ट पुन्हा तयार करा.

GitHub Actions मध्ये रिपॉझिटरी Secrets द्वारे प्रमाणपत्र द्या; कॉन्फिगर केल्यानंतर Windows बिल्ड स्वयंचलितपणे स्वाक्षरीकृत आणि पडताळले जातात:

| Secret | तपशील |
| --- | --- |
| `CAREFREE_SIGN_PFX_BASE64` | `.pfx` प्रमाणपत्र फाइलचा Base64 मजकूर; कॉन्फिगर नसेल तर CI स्वाक्षरी वगळते |
| `CAREFREE_SIGN_PASSWORD` | PFX निर्यात संकेतशब्द; एन्क्रिप्ट नसेल तर रिकामा ठेवा |

प्रमाणपत्र फक्त बिल्ड टप्प्यादरम्यान तात्पुरते डिस्कवर लिहिले जाते आणि काम संपताच हटवले जाते. टाइमस्टॅम्प पत्ता `CAREFREE_SIGN_TIMESTAMP_URL` एन्व्हायर्नमेंट व्हेरिएबलद्वारे बदलता येतो.

### सर्व्हर

```sh
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

- डीफॉल्टनुसार `127.0.0.1:3000` वर ऐकते आणि सार्वजनिक इंटरनेटसाठी उघडे नाही.
- पोर्ट `TOONFLOW_SERVER_PORT` ने बदलता येतो.
- खरोखर स्थानिक नेटव्हर्क प्रवेश हवा असेल, तर `TOONFLOW_SERVER_HOST=0.0.0.0` सेट करा आणि फायरवॉलने स्रोत मर्यादित करा; त्याऐवजी अॅपमध्ये “डिव्हाइस इंटरकनेक्शन” सुरू करणे अधिक उत्तम, ते गरज असेल तेव्हाच वेगळ्या पोर्टवर ऐकते.
- कॉन्फिगरेशन, प्लगइन आणि वर्कस्पेस डीफॉल्टनुसार `data/` मध्ये साठवले जातात. दूरून वापरासाठी SSH टनेलद्वारे प्रवेश करा:

```sh
ssh -N -L 3000:127.0.0.1:3000 वापरकर्ता@सर्व्हर-पत्ता
```

## मॉडेल कॉन्फिगर करणे

सेटिंग्जमधील “मॉडेल सेवा” उघडा:

- **मजकूर मॉडेल**: OpenAI-सुसंगत पुरवठादार जोडा, एंडपॉइंट पत्ता, API Key आणि मॉडेल यादी भरा.
- **प्रतिमा / व्हिडिओ**: ComfyUI पुरवठादार स्थापित व कॉन्फिगर करा, स्थानिक ComfyUI पत्ता आणि वर्कफ्लो भरा.
- **आवाज**: स्थानिक TTS पुरवठादार स्थापित करा; डीफॉल्ट पत्ता `http://127.0.0.1:8880/v1` आहे, आणि `/audio/speech` शी सुसंगत कोणत्याही सेवेकडेही निर्देश करता येतो.
- **सानुकूल पुरवठादार**: सेटिंग्जमध्ये `.ts` अडॅप्टर फाइल्स आयात करून कोणतेही तृतीय-पक्षीय एंडपॉइंट विस्तारित करा.

API Key फक्त स्थानिक डेटा डिरेक्टरीत साठवली जाते, अपलोड केली जात नाही.

## Docker

रिपॉझिटरीमध्ये [Dockerfile](../../Dockerfile), [Compose कॉन्फिगरेशन](../../compose.yaml) आणि [बिल्ड वगळण्याचे नियम](../../.dockerignore) आहेत; इमेज Bun 1.4.3 वर आधारित आहे आणि त्यात FFmpeg समाविष्ट आहे.

```sh
docker compose up -d --build
```

- `http://127.0.0.1:3000` उघडा.
- डेटा `toonflowData` या नामित व्हॉल्यूममध्ये साठवला जातो (कंटेनरमध्ये `/app/data/` वर माउंट केलेला); कंटेनर थांबवल्यास किंवा पुन्हा तयार केल्यास डेटा जात नाही, म्हणून `docker compose down -v` वापरू नका.
- कंटेनरमधील सेवा `0.0.0.0` वर ऐकते; पोर्ट मॅपिंग किंवा रिव्हर्स प्रॉक्सीद्वारे प्रवेश स्रोत नियंत्रित करा.

नेहमीच्या कमांड:

```sh
docker compose logs -f toonflow
docker compose stop
docker compose start
docker compose down
```

## डेटा आणि गोपनीयता

- अॅप अनामित आकडेवारी किंवा टेलिमेट्री गोळा करत नाही किंवा अहवाल देत नाही.
- प्रकल्प, प्रॉम्प्ट, संभाषणे आणि तयार केलेली सामग्री स्थानिक डेटा डिरेक्टरीत साठवली जाते.
- तुम्ही मॉडेल पुरवठादार कॉन्फिगर केल्यानंतरच संबंधित एंडपॉइंटला विनंत्या पाठवल्या जातात; विनंत्यांची सामग्री त्या पुरवठादाराच्या सेवा अटींच्या अधीन असते.
- स्वयंचलित अपडेट्स डीफॉल्टनुसार बंद आहेत; सेटिंग्जमध्ये स्वयं-होस्ट केलेला अपडेट स्रोत कॉन्फिगर करता येतो.
