# Carefree｜AI शॉर्ट ड्रामा और कॉमिक ड्रामा के लिए अनंत कैनवास

शॉर्ट ड्रामा, कॉमिक ड्रामा और शॉर्ट वीडियो क्रिएटर्स के लिए एक लोकल AI क्रिएशन टूल: अनंत कैनवास पर स्क्रिप्ट लिखें, स्टोरीबोर्ड तैयार करें, पात्रों और दृश्यों को व्यवस्थित करें, और इमेज तथा वीडियो जनरेट करें।

Carefree एक पूरी तरह से लोकल AI क्रिएशन टूल है। प्रोजेक्ट, एसेट, बातचीत और जनरेट किए गए नतीजे आपके अपने डिवाइस पर सहेजे जाते हैं, और किसी भी सर्वर पर उपयोग का डेटा नहीं भेजा जाता। मॉडल सेवाएँ आप स्वयं कॉन्फ़िगर करते हैं: कोई भी OpenAI-संगत एंडपॉइंट, लोकल ComfyUI, और लोकल या स्वयं-होस्ट की गई TTS सेवा।

## विशेषताएँ

| क्षमता | विवरण |
| --- | --- |
| अनंत कैनवास | एक ही कैनवास पर स्क्रिप्ट, स्टोरीबोर्ड, पात्र, दृश्य और वीडियो क्लिप व्यवस्थित करें; समूह बनाना और कनेक्शन समर्थित हैं। |
| टेक्स्ट क्रिएशन | किसी भी OpenAI-संगत टेक्स्ट एंडपॉइंट से जोड़ें और टेक्स्ट नोड में स्क्रिप्ट, पात्रों की सेटिंग और शॉट विवरण लिखें। |
| इमेज जनरेशन | स्वयं-होस्ट किए गए ComfyUI वर्कफ़्लो से पात्रों की टर्नअराउंड शीट, दृश्य और स्टोरीबोर्ड इमेज बनाएं। |
| वीडियो जनरेशन | ComfyUI या तृतीय-पक्ष मीडिया एंडपॉइंट से वीडियो शॉट बनाएं; कई संदर्भ एसेट और जनरेशन रद्द करने की सुविधा। |
| वॉइस जनरेशन | OpenAI-संगत `/audio/speech` एंडपॉइंट से जोड़ें; लोकल TTS तैनात करके ऑफ़लाइन डबिंग करें। |
| एसेट मैनेजमेंट | इमेज, वीडियो और ऑडियो सभी एसेट लाइब्रेरी में जाते हैं, जहाँ आप उन्हें देख, व्यवस्थित और डाउनलोड कर सकते हैं। |
| लोकल-फ़र्स्ट | डिफ़ॉल्ट रूप से सेवा केवल इसी मशीन पर सुनती है; ज़रूरत पड़ने पर डिवाइस इंटरकनेक्शन चालू करके लोकल नेटवर्क में साझा करें। |
| बहुभाषी | इंटरफ़ेस 21 भाषाओं का समर्थन करता है। |

उपलब्ध मॉडल, रिज़ॉल्यूशन, अवधि और ऑडियो क्षमताएँ आपके द्वारा कॉन्फ़िगर किए गए प्रोवाइडर और वर्कफ़्लो पर निर्भर करती हैं।

### सामान्य क्रिएशन वर्कफ़्लो

1. **स्क्रिप्ट और स्टोरीबोर्ड**: टेक्स्ट नोड से कहानी, पात्रों की सेटिंग और शॉट विवरण व्यवस्थित करें और भाषा मॉडल की मदद से उन्हें बेहतर बनाते जाएँ।
2. **पात्र और दृश्य**: संदर्भ इमेज आयात करें, या इमेज जनरेशन नोड से पात्र, दृश्य और स्टोरीबोर्ड इमेज बनाएं।
3. **वीडियो शॉट**: टेक्स्ट और इमेज संदर्भ जोड़ें, वीडियो मॉडल और जनरेशन मोड चुनें, और शॉट-दर-शॉट जनरेट करें।
4. **प्रीव्यू और एक्सपोर्ट**: कैनवास पर इमेज और वीडियो क्लिप देखें और व्यवस्थित करें, फिर पोस्ट-प्रोडक्शन के लिए एसेट डाउनलोड करें।

## क्लाइंट इंस्टॉल करना

| सिस्टम | विवरण |
| --- | --- |
| Windows | इंस्टॉलर चलाएँ; इंस्टॉलर स्वचालित रूप से WebView2 का पता लगाकर उसे इंस्टॉल करता है। अगर इंस्टॉल के बाद ऐप खुलते ही बंद हो जाए, तो [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) मैन्युअल रूप से इंस्टॉल करें। |
| macOS (Apple Silicon) | Carefree को “Applications” में खींचें और सीधे खोलें। अगर macOS कहे कि डेवलपर सत्यापित नहीं है, तो “System Settings → Privacy & Security” में जाकर अनुमति दें। |

`carefree://` URL स्कीम ऐप के भीतर रीस्टार्ट और डीप लिंक के लिए उपयोग होती है।

## सोर्स से चलाना

[Bun 1.4.3](https://bun.sh/docs/installation) आवश्यक है।

```sh
git clone <आपके-रिपॉज़िटरी-का-URL> carefree
cd carefree
bun install --frozen-lockfile

# डेवलपमेंट मोड: Web और Server एक साथ शुरू करें
bun run dev
```

`http://127.0.0.1:3000` खोलें। पहली बार चलाने पर अंतर्निहित नोड, टूल और प्लगइन शुरू होते हैं और `myProject` कार्यशील डायरेक्टरी बनती है।

### बिल्ड करना

```sh
# नोड, एक्सटेंशन, Web और Server बिल्ड करें
bun run build

# स्टैंडअलोन Server आर्टिफ़ैक्ट बिल्ड करें
bun run build:server

# डेस्कटॉप क्लाइंट बिल्ड करें
bun run build:desktop
bun run package:desktop
```

Windows इंस्टॉलर डिफ़ॉल्ट रूप से हस्ताक्षरित नहीं होते। पब्लिश करने से पहले निम्न एनवायरनमेंट वेरिएबल सेट करें; इसके बाद `bun run build:desktop` / `bun run package:desktop` स्वचालित रूप से `signtool` से चारों लॉन्चर (`startupLauncher.exe`, `protocolLauncher.exe`, `saveFileDialog.exe`, `updateHelper.exe`), इंस्टॉलर सहायक प्रोग्राम (`checkWebView2.exe`, `checkRunning.exe`) और अंतिम `Setup.exe` पर हस्ताक्षर और सत्यापन करेंगे:

| वेरिएबल | विवरण |
| --- | --- |
| `CAREFREE_SIGN_PFX` | `.pfx` सर्टिफ़िकेट का पूर्ण पथ; सेट न हो तो हस्ताक्षर छोड़ दिए जाते हैं |
| `CAREFREE_SIGN_PASSWORD` | सर्टिफ़िकेट पासवर्ड; सर्टिफ़िकेट एन्क्रिप्टेड न हो तो खाली छोड़ें |
| `CAREFREE_SIGN_TIMESTAMP_URL` | RFC3161 टाइमस्टैम्प सेवा, डिफ़ॉल्ट `http://timestamp.digicert.com` |
| `SIGNTOOL_PATH` | `signtool.exe` का पथ; डिफ़ॉल्ट रूप से Windows SDK से स्वचालित रूप से खोजा जाता है |

Windows x64 वातावरण और Windows SDK आवश्यक है। ऐप का मुख्य प्रोग्राम इंक्रीमेंटल अपडेट tar के अंदर है और इस हस्ताक्षर के दायरे में नहीं आता; अगर उसे हस्ताक्षरित करना हो, तो पहले ऐप फ़ाइल पर हस्ताक्षर करें, फिर tar और अपडेट मेनिफ़ेस्ट दोबारा बनाएं।

GitHub Actions में सर्टिफ़िकेट रिपॉज़िटरी Secrets से दें; कॉन्फ़िगर करने के बाद Windows बिल्ड स्वचालित रूप से हस्ताक्षरित और सत्यापित होते हैं:

| Secret | विवरण |
| --- | --- |
| `CAREFREE_SIGN_PFX_BASE64` | `.pfx` सर्टिफ़िकेट फ़ाइल का Base64 टेक्स्ट; कॉन्फ़िगर न हो तो CI हस्ताक्षर छोड़ देता है |
| `CAREFREE_SIGN_PASSWORD` | PFX एक्सपोर्ट पासवर्ड; एन्क्रिप्टेड न हो तो खाली छोड़ें |

सर्टिफ़िकेट केवल बिल्ड स्टेप के दौरान अस्थायी रूप से डिस्क पर लिखा जाता है और जॉब खत्म होते ही हटा दिया जाता है। टाइमस्टैम्प पता `CAREFREE_SIGN_TIMESTAMP_URL` एनवायरनमेंट वेरिएबल से बदला जा सकता है।

### सर्वर

```sh
bun run build:server
mkdir -p data/workspaces/myProject
bun run start:server
```

- डिफ़ॉल्ट रूप से `127.0.0.1:3000` पर सुनता है और सार्वजनिक इंटरनेट के लिए खुला नहीं है।
- पोर्ट `TOONFLOW_SERVER_PORT` से बदला जा सकता है।
- अगर वाकई लोकल नेटवर्क एक्सेस चाहिए, तो `TOONFLOW_SERVER_HOST=0.0.0.0` सेट करें और फ़ायरवॉल से स्रोत सीमित करें; इसके बजाय ऐप में “डिवाइस इंटरकनेक्शन” चालू करना बेहतर है, जो केवल ज़रूरत पड़ने पर अलग पोर्ट पर सुनता है।
- कॉन्फ़िगरेशन, प्लगइन और वर्कस्पेस डिफ़ॉल्ट रूप से `data/` में सहेजे जाते हैं। दूर से उपयोग के लिए SSH टनल से जुड़ें:

```sh
ssh -N -L 3000:127.0.0.1:3000 उपयोगकर्ता@सर्वर-पता
```

## मॉडल कॉन्फ़िगर करना

सेटिंग्स में “मॉडल सेवाएँ” खोलें:

- **टेक्स्ट मॉडल**: OpenAI-संगत प्रोवाइडर जोड़ें, एंडपॉइंट पता, API Key और मॉडल सूची भरें।
- **इमेज / वीडियो**: ComfyUI प्रोवाइडर इंस्टॉल और कॉन्फ़िगर करें, लोकल ComfyUI पता और वर्कफ़्लो भरें।
- **वॉइस**: लोकल TTS प्रोवाइडर इंस्टॉल करें; डिफ़ॉल्ट पता `http://127.0.0.1:8880/v1` है, और इसे `/audio/speech` के अनुरूप किसी भी सेवा पर इंगित किया जा सकता है।
- **कस्टम प्रोवाइडर**: सेटिंग्स में `.ts` अडैप्टर फ़ाइलें आयात करके किसी भी तृतीय-पक्ष एंडपॉइंट का विस्तार करें।

API Key केवल लोकल डेटा डायरेक्टरी में सहेजी जाती हैं, अपलोड नहीं की जाती हैं।

## Docker

रिपॉज़िटरी में [Dockerfile](../../Dockerfile), [Compose कॉन्फ़िगरेशन](../../compose.yaml) और [बिल्ड इग्नोर नियम](../../.dockerignore) उपलब्ध हैं; इमेज Bun 1.4.3 पर आधारित है और इसमें FFmpeg शामिल है।

```sh
docker compose up -d --build
```

- `http://127.0.0.1:3000` पर खोलें।
- डेटा नामित वॉल्यूम `toonflowData` में सहेजा जाता है (कंटेनर के अंदर `/app/data/` पर माउंट); कंटेनर रोकने या फिर से बनाने पर डेटा नहीं जाता, इसलिए `docker compose down -v` का उपयोग न करें।
- कंटेनर में सेवा `0.0.0.0` पर सुनती है; पोर्ट मैपिंग या रिवर्स प्रॉक्सी से एक्सेस स्रोत नियंत्रित करें।

सामान्य कमांड:

```sh
docker compose logs -f toonflow
docker compose stop
docker compose start
docker compose down
```

## डेटा और गोपनीयता

- ऐप अनामित आँकड़े या टेलीमेट्री एकत्र या रिपोर्ट नहीं करता।
- प्रोजेक्ट, प्रॉम्प्ट, बातचीत और जनरेट की गई सामग्री लोकल डेटा डायरेक्टरी में सहेजी जाती है।
- मॉडल प्रोवाइडर कॉन्फ़िगर करने के बाद ही संबंधित एंडपॉइंट पर अनुरोध भेजे जाते हैं; अनुरोध की सामग्री उस प्रोवाइडर की सेवा शर्तों के अधीन है।
- स्वचालित अपडेट डिफ़ॉल्ट रूप से बंद हैं; सेटिंग्स में स्वयं-होस्ट किया गया अपडेट स्रोत कॉन्फ़िगर किया जा सकता है।
