# 角色卡

为同一个角色保存固定的身份、外观描述、不变项和参考图，供多个镜头复用。

## 使用

1. 填写角色名、身份、固定外观与不变项，可上传参考图或从素材库选择。
2. 点击「保存到素材库」，角色会保存到全局素材库的 `characters` 目录，其他画布和项目可直接选用。
3. 跨设备或跨安装复用时，点击「导出」生成 `.carefree-character.json` 角色包（字段与参考图内嵌）；在另一端的角色卡点击「导入」即可写入全局素材库并载入。
4. 把本节点的「角色提示词」和「参考图」同时连接到图片生成或视频生成节点，生成画面会沿用同一套外观描述和参考图。

角色卡只固定角色本身，动作、表情、镜头和场景仍由各生成节点的提示词决定。
